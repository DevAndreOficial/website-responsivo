# Agência de Viagens – Website Responsivo

Projeto de website responsivo que simula uma **agência de viagens**, desenvolvido como **treino de front-end** utilizando apenas **HTML, CSS e JavaScript puro (Vanilla JS)**.

## Sobre o Projeto

Este projeto foi criado com o objetivo de praticar conceitos fundamentais do desenvolvimento web, incluindo:

- Estruturação semântica com HTML5  
- Estilização com CSS3  
- Criação de layouts responsivos  
- Interações básicas com JavaScript

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla)

## Responsividade

O layout é totalmente responsivo, adaptando-se a diferentes tamanhos de tela:

- Desktop  
- Tablet  
- Mobile
